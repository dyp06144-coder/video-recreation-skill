# 参考视频拆解与表达机制分析

## 目标
理解参考视频表达什么、怎样展开、哪些具体关系值得继承。适用于剧情、纪录、生活记录、知识讲解、访谈、口播、广告、音乐、舞蹈、体育动作、动画、游戏与屏幕演示等视频，也允许混合形式。类型帮助观察，不决定固定公式。

## 从整体到细节
先完整观看并听取，再检查影响改编的关键片段。明确观看体验：理解知识、感受情绪、欣赏动作、跟随过程、体验音乐或其他实际目的。视频不一定有冲突、反转、产品或行动引导，没有就不添加。

识别真正存在的组织方式：故事推进、解释顺序、观察与记录、音乐段落、动作连续性、空间变化、视觉重复或其他关系。查看人物与物体、行为、机位、构图、声音、文字和图形如何共同表达。

对有语言的视频，将可靠转写与画面相互核对；对无对白的视频，用动作、音乐、画面状态和阅读节奏定位意义。只记录会影响复刻或改编的细节，避免逐帧罗列却没有解释。

## 建立证据
对重要事件标记源视频时间及可见、可听事实。解释这个选择对观众有什么作用，并把解释标为判断。动态效果需查看连续过程，单帧不能证明运动轨迹或声音关系。重复的系统可以共用说明，记录其变化和跨镜头延续。

无法访问、听清或看清时指出局限；转写或分析冲突时回看对应片段。没有原始证据不能声称已观看，也不能把标题或别人描述当成视频事实。

## 提炼可保留的关系
根据任务提出“源片证据 → 表达或吸引力机制 → 改编中应保留的关系 → 可以变化的形式”。例如知识视频可能依赖清楚的因果演示，舞蹈依赖动作与节拍，生活记录依赖观察细节和情绪递进；不要求所有视频都有开场钩子和反转。

用户强调爆款或吸睛时，具体分析注意力怎样建立、维持和释放。没有传播数据时，这只是对内容吸引力的解释，不是爆款原因的因果证明，不承诺复刻后获得相同传播效果。

## 交付
给出整片理解、带时间的关键事件或系统、应保留与可变的关系，以及不确定项。需要保留证据时注明截图或片段位置。输出用于指导新作品，不直接把源片秒数和全部表面细节锁成目标约束。
