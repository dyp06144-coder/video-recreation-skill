# 参考视频改编与关系保留

## 创作原则
将参考与用户请求一起思考：原片的价值怎样在新的主体、环境或内容中成立？保留有用的关系，再创造适合目标的表达。用户要求保留的可以是故事、笑点、动作轨迹、解释逻辑、音乐节奏、视觉风格或情绪，并非必然是广告效果。

## 识别作用与表现形式
替换对象前找出其实际作用及所有出场：人物可能是讲述者、行动者、旁白或头像；物体可能是道具、证据、信息载体或视觉焦点。跨镜头、图形和声音的相关表现一起处理，未要求改变的独立角色不自动替换。

动作允许变化时，保留它承担的功能，而不是机械照搬形式。若精确动作本身是用户要保留的内容，例如舞蹈或运动技术，则动作连续性就是目标，不可擅自换掉。新主体的身体、能力、场景和物理关系应支持新动作。

## 按实际视频选择改编判断
- 剧情与喜剧：人物动机、因果、铺垫、反应和回报是否继续成立。
- 知识与演示：解释顺序、证据和结论是否正确，新对象是否适用。
- 音乐、舞蹈与动作：节拍、动作路径、接触、协同和镜头关系是否保留。
- 纪录、生活与情绪作品：时间、观察细节、人物关系和氛围是否承接目标。
- 动画、动态图形与视觉作品：状态变化、对象连续性、空间与运动语言是否协调。
- 商业作品：产品使用、实际能力、证明和行动引导是否适合新产品。

这些是观察角度，不是互斥分类，也不是必填清单。一个作品可以使用多种关系。

## 将机制落实到目标
对重要关系建立“原片证据 → 保留的作用或机制 → 新版本具体表达 → 检查方式”。用户强调吸睛点时，必须说明新版如何具体再现；没有反转的作品不为了表格补反转。

重写内容可能需要重写台词、动作、场景或顺序。删除某个元素时考虑它承担的作用如何承接。多个参考明确各自贡献，解决冲突，而非混合所有表面特征。

将原片作为分析证据与把原片传入生成模型区分开。需要迁移动作或运镜等连续时间行为时，选取有关片段作为生成参考；不需要时可使用图片与文字建立新版本。

## 交付与复核
交付目标改编方案、关键镜头或事件与对应表。检查指定替换是否完整、保留关系是否实际呈现、新内容是否自洽。原片秒数是证据位置，目标时间随新内容和表演确定。

若创意本身不成立，回到方案修改；若执行偏离设计，修改具体素材或请求。不通过增加形容词掩盖问题。
